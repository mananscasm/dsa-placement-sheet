# DSA Revision Plan

## Daily Loop

1. Solve two new problems.
2. Re-solve one old problem without looking.
3. Write the pattern trigger in one sentence.
4. Note one edge case.

## Weekly Review

- Revisit all problems marked hard.
- Group mistakes by cause: missed pattern, syntax, edge case, time complexity, or unclear explanation.
- Re-solve three problems from the weakest topic.

## Before Interviews

- Practice explaining brute force first.
- State complexity before coding.
- Test with empty input, duplicates, sorted input, and maximum constraints.
